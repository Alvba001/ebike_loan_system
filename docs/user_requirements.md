# User Requirements

## 1. Admin
The Admin shall be able to:
- Log in to the system using their email and password.
- View a dashboard summarizing system status (total loans, pending loans, repayments).
- View a list of all loan applications.
- View detailed information for a specific loan application, including uploaded documents (ID Card, Utility Bill).
- Approve a loan application.
- Reject a loan application.
- Automatically generate a repayment schedule when a loan is approved.
- View the repayment schedule for a loan.
- View repayment history.

## 2. Borrower (Student/User)
The Borrower shall be able to:
- Register for an account providing their name, email, and password.
- Log in to the system.
- View a dashboard displaying their current loan status.
- Apply for a loan by selecting a bike model, loan amount, and duration.
- Provide personal details including NIN and BVN during the loan application.
- Upload required documents (ID Card, Utility Bill) in supported formats (JPG, PNG, PDF).
- Provide guarantor information (Name, Contact, ID, Employment details) as the second step of the application.
- View the status of their loan application (Pending, Approved, Rejected).
- View their repayment schedule if the loan is approved.
- Make loan repayments (or mark installments as paid).
- View their repayment history.

## 3. Guest
The Guest shall be able to:
- View the login page.
- View the registration page.
- Register for a new account.
